*info2_reto1

Este proyecto fue desarrollado como parte de la asignatura Informática 2, en el Departamento de Ingeniería Electrónica y de Telecomunicaciones de la Universidad de Antioquia.

El objetivo del software es revertir transformaciones binarias aplicadas previamente a una imagen, utilizando programación en C++ y el entorno de desarrollo Qt.

A partir de una serie de archivos .txt que contienen fragmentos del mapa de bits de una imagen enmascarada, el programa realiza un proceso iterativo de comparación y análisis de patrones a nivel de bit. A través de este análisis, es capaz de reconstruir progresivamente la imagen original.

---

## Tecnologías Utilizadas

- C++ (Programación modular)
- Qt para GUI
- Archivos de entrada/salida en .bmp y .txt


## Funcionalidades

- Revertir iterativamente una serie de imagenes transformadas de forma binaria
